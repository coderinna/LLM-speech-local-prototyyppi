## Laitteisto

LLM-Speech-Local-DEMO voidaan testata myös fyysisellä laitteistolla.

ALustava halpa alusta voisi olla testialustana **Raspberry Pi 5** -masiina.

### Suunniteltu laitteistokokoonpano

| Komponentti | Suunniteltu ratkaisu |
|---|---|
| Päätietokone | Raspberry Pi 5, 8 GB |
| Jäähdytys | Raspberry Pi 5 Active Cooler |
| Äänitulon laitteisto | USB-mikrofoni |
| Äänentoisto | Pienikokoinen kaiutin ja vahvistin |
| Tallennustila | 64 GB microSD-kortti |
| Virtalähde kehitystestaukseen | Raspberry Pi 5 USB-C, 27 W |
| Käyttöpainike | Push-to-talk-painike ja johdot |
| Akkuratkaisu | Sopiva 5 V virtalähde tai akkupaketti |

Mitä järempi rauta rakennetaan, sitä parempaa kielimallia voidaan sen sisälle tunkea.
